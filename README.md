# Практика рефакторинга

Todo-приложение из практической работы, реализация на основе ветки `upstream/refactor`.

## Выполненные задания

1. В `TaskAction` добавлены загрузка, добавление, изменение статуса и удаление задач.
2. `TaskViewModel.reduce` вызывает нужные UseCase и обновляет состояние экрана. Для Room Flow поддерживается одна активная подписка. Ошибки загрузки и изменений отображаются через `TaskState.Error`.
3. `CompleteTaskUseCase` отмечает задачу выполненной, ждёт 10 секунд и удаляет её.
4. `TaskViewModel` хранит отдельный `Job` для каждой изменяемой задачи. Снятие отметки или ручное удаление отменяет ожидающее автоудаление. Повторное выполнение запускает новый срок. Все корутины запускаются через `viewModelScope` и отменяются при очистке ViewModel.

## Проверка

```shell
bash ./gradlew :app:testDebugUnitTest :app:assembleDebug
```

Нужны JDK 17 и Android SDK 35. Путь к SDK задаётся локально в `local.properties`.

Для совместимости Kotlin и обработки Room используются Kotlin 2.0.21, KSP2 и Room 2.7.2.

Виртуальное время в тестах проверяет загрузку, добавление, статусы, удаление, ошибки, границу 10 секунд, отмену и повторное планирование, независимость задач и очистку ViewModel.

Если компилятор тестов сообщает `NoSuchFileException` и обрезает путь после запятой, скопируйте проект в папку без запятых и запустите команду там. Это ограничение обработки путей компилятором Kotlin в текущей конфигурации.

Проверено: сборка debug APK и 8 JVM-тестов. Запуск на устройстве не выполнялся: подключённого устройства или работающего эмулятора не было.
